# Linux Distro Explorer (DistroPedia)

An interactive Linux distribution showcase built with **React**, **HeroUI (v2)**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Features

- **Elliptical Distro Ring**: 8 major distributions mapped via trigonometry around a central Tux mascot.
- **Dynamic Laser Lines & Traveling Pulse**: SVG lines connecting Tux to distros with animated laser pulses traveling towards active nodes.
- **Breathing Tux Mascot**: Centered Tux with custom breathing animation and blurred glow ring.
- **Contextual Preview Card**: Smoothly animates outward in the node's quadrant showing distribution family, init system, and package manager.
- **Responsive Mobile Sheet**: Seamless transition to a mobile view with a scrollable chip row and bottom slide-up preview sheet.

## 🛠️ Stack

- **Framework**: React 18 + Vite
- **UI Library**: HeroUI (`@heroui/react`)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React + Bespoke Inline SVGs

## 📦 Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```
